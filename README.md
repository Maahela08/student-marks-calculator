# Student Marks Calculator

A simple Python project to calculate student marks, total, average, and grade.

## Features

- Accepts student name
- Accepts marks for three subjects
- Calculates total marks
- Calculates average marks
- Displays the student's grade

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open `main.py`.
3. Run the Python program.
4. Enter the student name and subject marks.

## Grade Criteria

| Average | Grade |
|--------:|:-----:|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |
